# Analizzatore Scanner Ecografico

Programma per Windows per l'**analisi di scanner ecografici**.

## Download

Scarica l'ultima versione dell'installer:

**[Setup_AnalizzatoreScannerEcografico.exe](https://github.com/Lucarini63/analizzatore-ecografico-download/releases/latest/download/Setup_AnalizzatoreScannerEcografico.exe)**

Tutte le versioni sono disponibili nella pagina [Releases](https://github.com/Lucarini63/analizzatore-ecografico-download/releases).

## Requisiti

- Windows 10 o Windows 11

## Installazione

1. Scarica il file `Setup_AnalizzatoreScannerEcografico.exe`.
2. Avvia il file e segui la procedura guidata.
3. Se Windows mostra l'avviso SmartScreen, seleziona **Ulteriori informazioni** e poi **Esegui comunque**.
